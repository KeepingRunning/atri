ATRI 首个服务器部署版本，面向同一台 Linux 服务器上的 ATRI + NapCat。

- 提供 Docker Compose 部署包，配置、人设、聊天记录和 NapCat 登录态独立持久化。
- 发布 `ghcr.io/keepingrunning/atri:0.1.0`，支持 Linux AMD64 和 ARM64。
- 镜像预装 Python、Node 和两个固定版本的 MCP，无需运行时安装依赖或下载本地模型。
- 包含正常停机、本地健康检查，以及仅更新 ATRI、失败后恢复旧镜像的 `deploy.sh`。
- 保留 Planner/Replyer、历史检索、图片理解、链接阅读、百炼转写及 24 小时缓存。
- 包含自动复读、独立 `/health` 命令与输出标点规则。

下载 `atri-0.1.0-deploy.tar.gz`，核对 `SHA256SUMS`，解压后按 `DEPLOYMENT.md` 配置和启动。
源码内的部署说明：<https://github.com/KeepingRunning/atri/blob/v0.1.0/docs/deployment.md>。

首次运行需要填写机器人 QQ 号、允许群、OneBot token 和模型 API Key，并在 NapCat 登录 QQ、配置反向 WebSocket。API Key、聊天数据、登录态均不包含在发布包内。若 GHCR 镜像保持私有，拉取前需要登录具有该包读取权限的 GitHub 账号。

本版本通过本地模拟接口测试与隔离容器检查；尚未在你的新服务器上完成 QQ 登录和平台链接实测。`/healthz` 的本地健康与 `connected` 分开报告，不代表模型、B站或文章解析后端均可用。更新期间 ATRI 会短暂离线，NapCat 保持运行。
